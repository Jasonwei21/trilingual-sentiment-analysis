## 第1章 产品概述

### 1.1 简介

三语情感极性分析台是一款面向中文（zh）、日语（ja）、英语（en）三种语言的文本情感极性判定工具。用户输入一个词、一句话或一段话后，系统自动完成语言识别、分词、情感词典匹配与规则加权，实时输出整体情感倾向分、极性标签以及匹配到的情感词明细，支持中日英混排文本的逐句分析。

工具面向两类用户：一是需要快速查看文本情感倾向的普通用户（提供免安装的图形界面版本）；二是从事情感分析研究、需要方法可复现与可引用的研究人员（提供完整的词典与规则说明文档、Python 源码与测试）。

### 1.2 主要功能

1. 自动语言识别：基于字符集统计自动判断文本为中文、日语或英语，无需手动切换；支持混排文本逐句识别。
2. 自动分词：中文使用 jieba，日语使用 fugashi + UniDic-lite，英语使用空格/正则分词。
3. 情感词典匹配：按语言选用对应情感词典，并支持否定、程度等构词拆分（如「不好」拆为「不 + 好」）。
4. 规则加权：否定词极性反转（含双重否定复原）与程度副词乘性加权。
5. 整体倾向评分：输出 -100（纯负面）至 +100（纯正面）的连续刻度分值与四类极性标签。
6. 结果明细：展示自动分词结果（按类型着色）、匹配情感词表（基础分值与加权后分值、否定与程度触发词）、逐句分析小结。
7. 方法透明：页面内置「本工具使用的词典与分词工具」说明卡

### 1.3 发行形态

| 形态 | 适用场景 | 是否需要安装 |
|---|---|---|
| Windows 版（exe） | 普通用户日常使用、分发给他人 | 否，解压即用 |
| macOS 版（.app） | Mac 用户日常使用、分发给他人 | 否，解压即用 |
| 便携版（单 HTML） | 任意电脑、U 盘携带、无管理员权限场景 | 否，双击即开 |
| Python 源码版 | 开发者、论文实验（精确形态素分析） | 需安装 Python 与依赖 |

## 第2章 快速开始

### 2.1 Windows 版 / macOS 版（推荐）

1. 将 `三语情感极性分析-Windows.zip`（约 39 MB）解压到任意目录。
2. 双击 `SentimentAnalysis.exe`（首次启动约 3～10 秒），浏览器自动打开分析界面。

macOS：将 `三语情感极性分析-mac.zip` 解压后双击 `SentimentAnalysis.app` 即可（首次打开如提示「无法验证开发者」，右键 → 打开）。打包方法见 `packaging/build_mac.command`（在 Mac 上双击一次即可）。
3. 若未自动打开，手动访问默认地址 http://127.0.0.1:8765。
4. 关闭浏览器标签页即自动退出（程序无窗口，后台静默运行）。

> ⚠️ 请保持文件夹完整：exe 与 `_internal` 目录必须在一起，不可单独拷贝 exe。杀软误报时选择「信任/放行」。

Windows 也可双击 `start.bat`（自动装依赖并启动；无 Python 时自动改开便携版），macOS / Linux 用 `./start.sh`。

## 第3章 界面说明

页面自上而下分为三个区域：输入区、分析结果区、资源说明卡。

### 3.1 文本输入区

多行文本框，支持粘贴任意长度文本（词、句子或段落）。下方提供四个示例按钮（中文好评、中文差评、中日混排、英文混评）可一键填充体验；右侧实时显示字数。输入后约 0.35 秒自动开始分析，无需点击按钮。

### 3.2 语言识别栏

显示识别到的语言徽标（中文 / 日本語 / English / 未知）、置信度进度条，以及汉字 / 假名 / 拉丁字符数分布。判别规则：出现假名判为日语；否则出现汉字判为中文；否则出现拉丁字母判为英语；置信度为判定脚本字符占比。

### 3.3 极性刻度条与标签

页面核心输出。大号数字显示整体倾向分（-100 ～ +100），右侧为极性标签：

- **正面**：倾向分 > +10
- **负面**：倾向分 < -10
- **中性**：-10 ≤ 倾向分 ≤ +10（弱倾向带，避免正负相抵被误判）
- **无法判断**：未命中任何情感词，或语言无法识别

下方为渐变刻度条：左端绿色代表纯负面（-100），中点灰色代表中性（0），右端红色代表纯正面（+100）；黑色指针指示当前分值位置。

### 3.4 统计信息

显示原始加权总分、命中情感词个数、句子数三项统计。

### 3.5 自动分词区

以彩色标签展示分词结果：红色为正向情感词（附加权分值）、绿色为负向情感词、橙色为否定词、蓝色为程度副词、灰色为普通词。

### 3.6 匹配情感词表

表格列出每个命中词条：词条（含词面）、基础分值、加权后分值、是否否定及触发词、程度词及权重。若未命中任何词，显示「没有命中情感词典的词——无法判断极性」。

### 3.7 逐句分析

多句文本时，按句展示：语言标注、句子内容、极性小刻度条与该句的标签和分值。各句独立判定后再聚合为整体结果，中日英混排段落也能正确处理。

### 3.8 词典与分词工具说明卡

页面底部常驻说明卡，注明各语言所用情感词典与分词工具、判定规则摘要，并指向方法说明文档，便于研究者溯源。

## 第4章 使用方法与结果解读

### 4.1 基本流程

输入文本 → 系统自动分析 → 查看极性刻度条与标签 → 需要时下查分词与匹配词明细。

### 4.2 使用示例

| 输入 | 倾向分 | 标签 | 说明 |
|---|---|---|---|
| 非常不好 | -100 | 负面 | 「好」被否定词「不」反转，程度词「非常」放大 2 倍 |
| 不太好 | -75 | 负面 | 「不太好」整体视为弱化否定（好 +1.5 反转） |
| 爱，恨 | 0 | 中性 | 正负词各一（±1.5），平均后落在弱倾向带 |
| not bad | +75 | 正面 | 双重否定复原，bad(-1.5) 反转为 +1.5 |
| not very good | -75 | 负面 | 程度词 very 加权 1.5 后再反转 |
| 良くない | -50 | 负面 | 日语后置否定「ない」反转「良い」 |
| とても嬉しい | +80 | 正面 | 嬉しい(+1.0) 经程度词「とても」×1.6 |
| 玻璃幕墙 | — | 无法判断 | 无命中情感词 |

### 4.3 匹配词字段说明

- **基础分**：情感词典中该词的极性强度（正=正面、负=负面，绝对值=强度）。
- **加权后**：经否定反转与程度加权后的最终分值，`w = 基础分 × (-1)^否定 × 程度权重`。
- **否定**：显示「是（触发词）」表示该词被否定规则反转。
- **程度**：显示触发的程度词及其权重（如 非常 ×2）。

## 第5章 判定原理与语言资源

> 本章为快速概述；完整方法、词表溯源、公式细节、局限性与参考文献见文末**第二部分**。

### 5.1 总体流程

文本 → 分句 → 逐句语言识别 → 分词 → 词典命中（含构词拆分）→ 否定反转 × 程度加权 → 词级加权分 → 聚合为倾向分与标签。

### 5.2 情感词典

| 语言 | 词典资源 | 内置词条数 | 分值约定（完整资源） |
|---|---|---|---|
| 中文 | 知网 HowNet 情感分析用词语集 | 8754 | 情感类 ±1.5，评价类 ±1.0 |
| 日语 | 単語感情極性対応表・日本語評価極性辞書 | 13575 | p → +1.0，n → -1.0，e 不收录 |
| 英语 | MPQA Subjectivity Lexicon | 6451 | strong ±1.5，weak ±1.0 |

> 📌 随工具内置的是三个标准词典的**完整版转换词典**（HowNet 情感分析用词语集(beta 版)、単語感情極性対応表 pn.csv.m3.120408+wago、MPQA 2005），原始文件存于 `dictionaries/` 供溯源；转换脚本为 `tools/build_full_lexicons.py`。研究实验请注明词典版本与词条数。

### 5.3 分词与语言识别

中文 jieba 0.42.1（精确模式）；日语 fugashi 1.5.2 + UniDic-lite 1.0.8（取词面与词元中能在词表命中的形式，消除 ない/無い、とても/迚も 等词元差异）；英语小写化 + 缩写展开（n't → not、cannot → can not）后按字母串切分。便携版采用词表最长匹配分词（与源码版缺分词库时的降级方案一致）。

### 5.4 否定与程度规则

- **否定词反转**：窗口大小 2；中文/英语向左看（不好、not good），日语向右看（良くない）；窗口内否定词个数为奇数则极性取反，偶数（双重否定）复原。含构词拆分：不好 → 不+好，良くない → 良い+ない。
- **程度副词加权**：窗口大小 2（修饰语前置），权重连乘、上限 3.0。内置程度词示例：非常 ×2.0、很 ×1.5、稍微 ×0.5、very ×1.5、extremely ×2.0、とても ×1.6、少し ×0.5。

### 5.5 计分与标签

词级：`wᵢ = bᵢ × (-1)^nᵢ × Dᵢ`（b 为基础分，n 为否定标记，D 为程度权重乘积）。
整体倾向分：`I = clip(平均加权分 / 2.0, -1, +1) × 100`；无命中时无定义。
标签：I > +10 正面；I < -10 负面；其余中性；无命中或语言无法识别为无法判断。

### 5.6 与论文写作的关系

完整的词表内容、参数表、公式推导、局限性与参考文献见文末「第二部分 方法说明与参考文献」。

## 第6章 常见问题与故障排除

**Q1：双击 exe 没有反应？**
请确认 exe 与 `_internal` 目录在同一文件夹且未被破坏（解压时勿只拷贝 exe）。首次启动较慢（3～10 秒）属正常；若仍无反应，右键以管理员身份运行一次。

**Q2：杀毒软件报警？**
程序未做商业签名，部分杀软可能误报。选择「信任 / 放行 / 添加到白名单」即可。

**Q3：浏览器打开后显示无法访问？**
端口可能因占用而变化（8765～8784）；若自动打开的页面无法访问，请尝试相邻端口。

**Q4：为什么显示「无法判断」？**
三种情况：文本中没有命中情感词典的词（如纯数字、专有名词）；语言无法识别（如韩文）；词典文件缺失（会同时给出警告）。这是刻意设计，避免无依据地给出极性。

**Q5：为什么某句话的结果与预期不符？**
本工具为词典 + 规则方法：未登录词不参与计分；反讽、转折、长距离否定不在建模范围内（详见 METHODOLOGY.md §8 局限性）。可在结果区查看匹配词明细，确认是哪些词决定了分值。

**Q6：便携版与 exe 结果会不一样吗？**
词典与判定规则完全一致，且经自动化逐值对拍；唯一差异是便携版使用词表最长匹配分词（缺分词库时的降级方案），极少数切分歧义场景可能与 jieba/fugashi 略有出入。论文实验请使用 exe 版或源码版。

**Q7：如何更换或扩充词典？**
编辑 `trilingual_sentiment/data/` 下的 CSV/TXT 文件即可（格式见文件头注释）；或在代码中调用 `analyzer.add_word()` / `analyzer.load_lexicon()`。便携版需重跑 `python tools/build_portable.py` 同步。

**Q8：可以在 macOS / Linux 使用吗？**
可以：便携版直接可用；源码版执行 `./start.sh`；另有 macOS 版 `.app`（`packaging/build_mac.command` 在 Mac 上双击打包即可）。

**Q9：如何修改端口？**
源码版：`PORT=9000 python webapp/app.py`。exe 版会自动在 8765～8784 中寻找空闲端口。

**Q10：空输入、未知语言代码会怎样？**
空输入（含纯空白）抛出 ValueError（API 返回 400）；未知语言代码返回「无法判断」并附警告；词典缺失返回「无法判断」并附警告（不静默降级）。

## 第7章 二次开发与 API

### 7.1 REST API

`POST /api/analyze`，请求体 `{"text": "文本"}`，空文本返回 HTTP 400。返回字段：

| 字段 | 含义 |
|---|---|
| language | 整体语言识别结果（code / name / confidence / counts） |
| index | 整体倾向分（-100～100，无命中为 null） |
| label | 极性标签 |
| score | 原始加权总分 |
| matched_count / sentence_count | 命中词数 / 句子数 |
| sentences[] | 逐句结果（语言、标签、index、matched、tokens、warnings） |

### 7.2 Python API

```python
from trilingual_sentiment import SentimentAnalyzer
az = SentimentAnalyzer()
r = az.analyze("非常不好", "zh")   # r.label / r.score / r.matched
d = az.explain("非常好", "zh")     # 含分词标注 tokens
```

### 7.3 扩展点

- **词典**：`trilingual_sentiment/data/*.csv`（word,score）；加载器支持 HowNet 目录、MPQA .lex、単語感情極性対応表 pn.csv。
- **规则**：`data/*_negation.txt`（否定词）、`data/*_degree.csv`（程度词权重）；窗口大小与权重上限在 `SentimentAnalyzer(...)` 构造参数中配置。
- **新语言**：注册 `LanguageProfile`（分词器 + 词典 + 规则）即可。

## 第二部分 方法说明与参考文献

> 本部分说明本系统所用词典资源、判定规则与计分方法，包括词典来源与引用、公式、参数与局限性。
> 文中数据与 `trilingual_sentiment/` 代码实现一一对应（版本见 §7 参数总表）。

---

### 1. 任务定义与总体流程

对输入的一段文本（词或句子），自动完成：

1. **语言识别**（中文 zh / 日语 ja / 英语 en）；
2. **分句与分词**；
3. **情感词典匹配**（含否定/程度构词拆分）；
4. **规则加权**（否定词极性反转、程度副词加权）；
5. 输出：**整体倾向分（-100 ~ +100）**、**极性标签**（正面 / 负面 / 中性 / 无法判断）、**匹配情感词明细**（每个词的基础分值与加权后分值）。

流程形式化：

```
文本 → 分句 → 逐句语言识别 → 分词 → 词典命中(含构词拆分)
     → 否定反转 × 程度加权 → 词级加权分 wᵢ
     → 聚合为倾向分 I 与极性标签 L
```

#### 2.1.1 基础分值（base score）约定

词典命中词 *w* 赋予基础分值 *b(w)*，符号表示极性方向、绝对值表示强度：

- **HowNet（完整词集接入时）**：正面情感词语 **+1.5**，负面情感词语 **-1.5**，正面评价词语 **+1.0**，负面评价词语 **-1.0**（情感类强度高于评价类）；
- **単語感情極性対応表**：p → **+1.0**，n → **-1.0**；e（中立）不进入情感词典；
- **MPQA**：priorpolarity=positive/negative 决定符号；type=strongsubj 强度 **1.5**，weaksubj 强度 **1.0**；both/neutral 不收录；
- **内置完整转换词典**（随系统分发，实验默认使用）：由三个标准词典的原始资源按上述约定转换而成（转换脚本 `tools/build_full_lexicons.py`），原始文件保存于 `dictionaries/` 供溯源。

### 3. 预处理

#### 3.1 语言自动识别（Web 界面逐句识别）

基于字符集统计的规则判定（无监督、可解释）：

- 文本中**出现假名**（平假名/片假名，U+3040–U+30FF）→ 判为 **ja**（假名是日语的决定性信号）；
- 否则**出现汉字**（U+3400–4DBF、U+4E00–9FFF、U+F900–FAFF）→ 判为 **zh**；
- 否则**出现拉丁字母** → 判为 **en**；
- 均无（如纯数字、谚文等）→ **unknown**，输出「无法判断」。

置信度 = 判定脚本字符数 ÷（汉字+假名+拉丁字符总数）；判定 ja 时判定脚本为「假名+汉字」。

#### 3.2 分句

按句末标点切分：`[。！？!?]+`、英文句点后接空白、`[\n；;]+`。逐句识别语言并判定，再聚合为段落整体结果（支持中日英混排）。

#### 3.3 分词与词形归一

| 语言 | 分词器                                          | 归一化处理                                                            |
| -- | -------------------------------------------- | ---------------------------------------------------------------- |
| zh | **jieba**（精确模式 `lcut`，v0.42.1）               | —                                                                |
| ja | **fugashi**（v1.5.2）+ **UniDic-lite**（v1.0.8） | 每个形态素在「词面→词元(lemma)」中取**能在词表命中**的形式（解决 UniDic 词元差异：ない↔無い、とても↔迚も） |
| en | 空格/正则分词                                      | 小写化；缩写展开：`n't → not`、`cannot → can not`；按字母串切分                   |

分词库缺失时的兜底：基于「情感词典∪否定词表∪程度词表」词表的**最长匹配**（日语含连用形还原：`〜く → 〜い`，如 良く→良い）。

### 4. 判定规则

#### 4.1 词典命中与构词拆分

对每个分词单元 *t*，按以下顺序命中情感词典：

1. **直接命中**：*t* 本身为词典词条；
2. **后缀否定拆分**（日语/英语）：*t* 以否定后缀结尾时剥去后缀回查词干  
   （良くない → 良い+**ない**；日语含连用形还原）；
3. **前缀否定拆分**（中文）：*t* 以否定前缀起始时剥去前缀回查词干  
   （不好 → **不**+好）；若词干仍含程度前缀（不太好 → 不+太+好），**只做极性反转、不套程度权重**（「不太 X」整体视为弱化否定）；
4. **程度前缀拆分**（各语言）：*t* 以程度副词起始时剥去前缀回查词干  
   （太慢 → **太**+慢），剥出的程度词按 §4.3 加权；
5. **词形还原**（日语）：连用形还原后回查（良く → 良い，不带否定）。

> 构词拆分（第 2–4 步）携带的否定/程度信息**计入该词自身**，不重复计入 §4.2/§4.3 的滑动窗口，避免双重计算。

#### 4.2 否定词反转规则

- **窗口**：以情感词为基准取大小为 **2** 的邻接窗口；
- **方向**：中文/英语向**左**看（否定语在情感词前：不好、not good）；日语向**右**看（否定语为后置要素：良く**ない**）；
- **反转**：窗口内否定词个数为**奇数**则极性取反，**偶数**（双重否定）则复原：  
  `sign = (-1)^(否定词个数 mod 2)`；
- 与 §4.1 的词缀否定按**异或**合成（同一否定事实只计一次）。

#### 4.3 程度副词加权规则

- **窗口**：情感词**左**侧大小为 **2** 的邻接窗口（修饰语前置是三种语言的共同惯例）；
- **加权**：窗口内程度词权重**连乘**，再与构词拆分剥出的程度词权重相乘；
- **截断**：总程度权重上限 **3.0**，防止多层修饰导致分值爆炸。

### 5. 分值计算与极性标签

#### 5.1 词级加权分

对第 *i* 个命中情感词：

```
wᵢ = bᵢ × (-1)^(nᵢ) × Dᵢ
```

- `bᵢ`：词典基础分值（§2.1.1）；
- `nᵢ ∈ {0,1}`：否定标记（词缀否定 XOR 窗口否定）；
- `Dᵢ = min( D_构词 × ∏ dⱼ , 3.0 )`：程度权重（§4.3）。

**示例**：「非常不好」→ 词干「好」b=+1.5（HowNet 正面情感类），否定「不」反转，程度「非常」×2.0 → w = 1.5 ×(-1)× 2.0 = **-3.0**。

#### 5.2 整体倾向分（-100 ~ +100）

设全文（可含多句、多语言）共命中 *m* 个情感词，加权分为 {w₁,…,w_m}：

```
I = clip( (Σwᵢ / m) / 2.0 , -1 , +1 ) × 100
```

- 以**平均加权分**为基础，段落长度不改变倾向强度的量纲；  
  |  |  |  |  |  |  
  | --- | --- | --- | --- | --- |
- 常数 **2.0** 为归一化单位：使「单个常规情感词（|b|=1.0）」落在 ±50，「增强后的极性词（|w|≥2.0）」打满 ±100；
- `m = 0`（无命中情感词）时 I 无定义，标签为「无法判断」。

#### 5.3 极性标签

| 条件                         | 标签       |
| -------------------------- | -------- |
| 无命中情感词，或语言无法识别（非 zh/ja/en） | **无法判断** |
| I > +10                    | **正面**   |
| I < -10                    | **负面**   |
| -10 ≤ I ≤ +10              | **中性**   |

阈值 ±10 为**弱倾向带**：避免正负相抵或极弱倾向被误判为明确正面/负面（如「爱，恨」I=0 → 中性）。

**示例**（实测，完整版词典）：

| 输入      | 命中               | I    | 标签   |
| ------- | ---------------- | ---- | ---- |
| 非常不好    | 好(+1.5)×(-1)×2.0 | -100 | 负面   |
| 不太好     | 好(+1.5)×(-1)     | -75  | 负面   |
| not bad | bad(-1.5)×(-1)   | +75  | 正面   |
| 爱，恨     | 爱(+1.5)、恨(-1.5)  | 0    | 中性   |
| 玻璃幕墙    | —                | 无定义  | 无法判断 |

### 6. 边界情况处理

| 情况                    | 处理                          |

### 8. 局限性（论文局限性部分可参考）

1. **规则窗口有限**：否定/程度窗口大小为 2，跨子句的长距离修饰（如「不是我认为的那种好」）无法覆盖；
2. **转折/让步不建模**：「但是/but/が」两侧的极性不做篇章级加权，逐句独立聚合，段落倾向为算术平均而非话语结构加权；
3. **词典覆盖受限**：未登录词（新词、领域词、拼写变体）不参与计分；完整词典可经加载器接入，但仍无法覆盖动态词汇；
4. **语用现象**：反讽、反问、双重修辞（如「好得不能再差」）按字面规则处理，易误判；
5. **多语言混排粒度**：按句识别语言并选用对应词典，句内混排（如「这个 design 很 nice」）以句级主导语言为准，非主导语言的词可能漏判；
6. **程度权重人工设定**：程度副词权重为经验赋值，未做语料拟合；不同领域可重新标定（权重表为外部 CSV，可替换）。

| 便携版引擎（JS 移植）  | `portable/engine.js`                                 |
| 便携版单文件（双击即用）  | `三语情感极性分析-便携版.html`（由 `tools/build_portable.py` 生成）  |

### 11. 便携版（免安装）说明

`三语情感极性分析-便携版.html` 为**单文件离线版**：内嵌判定引擎与词典数据，双击即可在浏览器中使用，  
无需安装 Python 或任何依赖。其**词典、否定/程度规则、加权公式、倾向分与标签阈值与 Python 版完全一致**，  
并经自动化对拍测试（`tests/portable_cases.js`，23 项用例与 Python 版断言值逐一核对）。

唯一差异在**分词实现**：便携版采用词表最长匹配分词（即 Python 版在缺少 jieba/fugashi 时的降级方案，含日语  
连用形还原 く→い）；Python 版在安装 jieba/fugashi 后使用精确形态素分析。词典命中与规则判定不受此差异影响，  
但若论文实验要求与 §3.3 完全一致的分词流程，请使用 Python 版运行实验并注明分词器版本。
