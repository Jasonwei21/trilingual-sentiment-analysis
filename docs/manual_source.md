## 第1章 产品概述

### 1.1 简介

三语情感极性分析台是一款面向中文（zh）、日语（ja）、英语（en）三种语言的文本情感极性判定工具。用户输入一个词、一句话或一段话后，系统自动完成语言识别、分词、情感词典匹配与规则加权，实时输出整体情感倾向分、极性标签以及匹配到的情感词明细，支持中日英混排文本的逐句分析。

工具面向两类用户：一是需要快速查看文本情感倾向的普通用户（提供免安装的图形界面版本）；二是从事情感分析研究、需要方法可复现与可引用的研究人员（提供完整的词典与规则说明文档、Python 源码与测试）。

### 1.2 主要功能

1. 自动语言识别：基于字符集统计自动判断文本为中文、日语或英语，无需手动切换；支持混排文本逐句识别。
2. 自动分词：中文使用 jieba，日语使用 fugashi + UniDic-lite，英语使用空格/正则分词。
3. 情感词典匹配：按语言选用对应情感词典，并支持否定、程度等构词拆分（如「不好」拆为「不 + 好」）。
4. 规则加权：否定词极性反转（含双重否定复原）与程度副词乘性加权。
5. 整体倾向评分：输出 -100（纯负面）至 +100（纯正面）的连续刻度分值与四类极性标签（正面 / 负面 / 中性 / 无法判断）。
6. 结果明细：展示自动分词结果（按类型着色）、匹配情感词表（基础分值与加权后分值、否定与程度触发词）、逐句分析小结。
7. 方法透明：页面内置「本工具使用的词典与分词工具」说明卡

## 第3章 安装与启动

### 3.1 Windows 版（推荐）

1. 将「三语情感极性分析-Windows.zip」解压到任意目录（如 D:\SentimentAnalysis）。
2. 双击 SentimentAnalysis.exe。首次启动约需 3～10 秒。
3. 浏览器将自动打开分析界面；若未自动打开，请手动访问默认地址 http://127.0.0.1:8765。
4. 使用完毕后关闭浏览器标签页即自动退出（程序无窗口，后台静默运行）。

注意：请保持文件夹完整，exe 与 _internal 目录必须在一起，不可单独拷贝 exe；整个文件夹可任意移动、复制、用 U 盘分发。若杀毒软件提示未签名程序，选择「信任/放行」即可。

### 3.2 便携版

直接双击「三语情感极性分析-便携版.html」，即可在浏览器中使用，无需安装、无需启动服务。

### 3.3 源码版

    pip install -r requirements.txt
    python webapp/app.py --open

默认地址 http://127.0.0.1:8765；可用环境变量 PORT 修改端口。命令行单条判定：

    python -m trilingual_sentiment "非常不好" zh

### 3.4 启动器脚本

- Windows：双击 start.bat——自动检查 Python、安装依赖并启动；若检测不到 Python，自动改为打开便携版。
- macOS / Linux：执行 ./start.sh，逻辑相同。

## 第4章 界面说明

页面自上而下分为三个区域：输入区、分析结果区、资源说明卡。

### 4.1 文本输入区

多行文本框，支持粘贴任意长度文本（词、句子或段落）。下方提供四个示例按钮（中文好评、中文差评、中日混排、英文混评）可一键填充体验；右侧实时显示字数。输入后约 0.35 秒自动开始分析，无需点击按钮。

### 4.2 语言识别栏

显示识别到的语言徽标（中文 / 日本語 / English / 未知）、置信度进度条，以及汉字 / 假名 / 拉丁字符数分布。判别规则：出现假名判为日语；否则出现汉字判为中文；否则出现拉丁字母判为英语；置信度为判定脚本字符占比。

### 4.3 极性刻度条与标签

页面核心输出。大号数字显示整体倾向分（-100 ～ +100，正数倾向正面、负数倾向负面），右侧为极性标签徽标：

- 正面：倾向分 > +10
- 负面：倾向分 < -10
- 中性：-10 ≤ 倾向分 ≤ +10（弱倾向带，避免正负相抵被误判）
- 无法判断：未命中任何情感词，或语言无法识别

下方为渐变刻度条：左端绿色代表纯负面（-100），中点灰色代表中性（0），右端红色代表纯正面（+100）；黑色指针指示当前分值位置。

### 4.4 统计信息

显示原始加权总分、命中情感词个数、句子数三项统计。

### 4.5 自动分词区

以彩色标签（chips）展示分词结果：红色为正向情感词（附加权分值）、绿色为负向情感词、橙色为否定词、蓝色为程度副词、灰色为普通词。

### 4.6 匹配情感词表

表格列出每个命中词条：词条（含词面）、基础分值、加权后分值、是否否定及触发词、程度词及权重。若未命中任何词，显示「没有命中情感词典的词——无法判断极性」。

### 4.7 逐句分析

多句文本时，按句展示：语言标注、句子内容、极性小刻度条与该句的标签和分值。各句独立判定后再聚合为整体结果，因此中日英混排段落也能正确处理。

### 4.8 词典与分词工具说明卡

页面底部常驻说明卡，注明各语言所用情感词典与分词工具、判定规则摘要，并指向方法说明文档，便于研究者溯源。

## 第5章 使用方法与结果解读

### 5.1 基本流程

输入文本 → 系统自动分析 → 查看极性刻度条与标签 → 需要时下查分词与匹配词明细。

### 5.2 使用示例

| 输入 | 倾向分 | 标签 | 说明 |
|---|---|---|---|
| 非常不好 | -100 | 负面 | 「好」被否定词「不」反转，程度词「非常」放大 2 倍 |
| 不太好 | -50 | 负面 | 「不太好」整体视为弱化否定，不套用程度放大 |
| 好和坏 | 0 | 中性 | 正负词各一，平均后落在弱倾向带 |
| not bad | +50 | 正面 | 双重否定复原，负词反转为正 |
| not very good | -75 | 负面 | 程度词 very 加权 1.5 后再反转 |
| 良くない | -50 | 负面 | 日语后置否定「ない」反转「良い」 |
| とても嬉しい | +100 | 正面 | 程度词「とても」加权 1.6 倍 |
| 今天天气 | — | 无法判断 | 无命中情感词 |

### 5.3 匹配词字段说明

- 基础分：情感词典中该词的极性强度（正=正面、负=负面，绝对值=强度）。
- 加权后：经否定反转与程度加权后的最终分值，计算式为 w = 基础分 × (-1)^否定 × 程度权重。
- 否定：显示「是（触发词）」表示该词被否定规则反转。
- 程度：显示触发的程度词及其权重（如 非常 ×2）。

## 第6章 判定原理与语言资源

### 6.1 总体流程

文本 → 分句 → 逐句语言识别 → 分词 → 词典命中（含构词拆分）→ 否定反转 × 程度加权 → 词级加权分 → 聚合为倾向分与标签。

### 6.2 情感词典

| 语言 | 词典资源 | 内置词条数 | 分值约定（完整资源） |
|---|---|---|---|
| 中文 | 知网 HowNet 情感分析用词语集 | 61 | 情感类 ±1.5，评价类 ±1.0 |
| 日语 | 単語感情極性対応表・日本語評価極性辞書 | 38 | p → +1.0，n → -1.0，e 不收录 |
| 英语 | MPQA Subjectivity Lexicon | 38 | strong ±1.5，weak ±1.0 |

说明：随工具内置的是三个标准词典的精选子集（分值人工标定于 [-2, +2]），保证开箱即用；完整词典可通过加载器（from_hownet_dir / from_jp_table / from_mpqa）无损接入。研究实验建议使用完整词典并注明版本与词条数。

### 6.3 分词与语言识别

中文 jieba 0.42.1（精确模式）；日语 fugashi 1.5.2 + UniDic-lite 1.0.8（取词面与词元中能在词表命中的形式，消除 ない/無い、とても/迚も 等词元差异）；英语小写化 + 缩写展开（n't → not、cannot → can not）后按字母串切分。便携版采用词表最长匹配分词（与源码版缺分词库时的降级方案一致）。

### 6.4 否定与程度规则

- 否定词反转：窗口大小 2；中文/英语向左看（不好、not good），日语向右看（良くない）；窗口内否定词个数为奇数则极性取反，偶数（双重否定）复原。含构词拆分：不好 → 不+好，良くない → 良い+ない。
- 程度副词加权：窗口大小 2（修饰语前置），权重连乘、上限 3.0。内置程度词示例：非常 ×2.0、很 ×1.5、稍微 ×0.5、very ×1.5、extremely ×2.0、とても ×1.6、少し ×0.5。

### 6.5 计分与标签

词级：wᵢ = bᵢ × (-1)^nᵢ × Dᵢ（b 为基础分，n 为否定标记，D 为程度权重乘积）。
整体倾向分：I = clip(平均加权分 / 2.0, -1, +1) × 100；无命中时无定义。
标签：I > +10 正面；I < -10 负面；其余中性；无命中或语言无法识别为无法判断。

### 6.6 与论文写作的关系

## 第7章 常见问题与故障排除

**Q1：双击 exe 没有反应？**
请确认 exe 与 _internal 目录在同一文件夹且未被破坏（解压时勿只拷贝 exe）。首次启动较慢（3～10 秒）属正常；若仍无反应，右键以管理员身份运行一次。

**Q2：杀毒软件报警？**
程序未做商业签名，部分杀软可能误报。选择「信任 / 放行 / 添加到白名单」即可。

**Q3：浏览器打开后显示无法访问？**
端口可能因占用而变化（8765～8784）；若自动打开的页面无法访问，请尝试相邻端口。

**Q4：为什么显示「无法判断」？**
三种情况：文本中没有命中情感词典的词（如纯数字、专有名词）；语言无法识别（如韩文）；词典文件缺失（会同时给出警告）。这是刻意设计，避免无依据地给出极性。

**Q5：为什么某句话的结果与预期不符？**
本工具为词典 + 规则方法：未登录词不参与计分；反讽、转折、长距离否定不在建模范围内（详见方法说明 §8 局限性）。可在结果区查看匹配词明细，确认是哪些词决定了分值。

**Q6：便携版与 exe 结果会不一样吗？**
词典与判定规则完全一致，且经自动化逐值对拍；唯一差异是便携版使用词表最长匹配分词（缺分词库时的降级方案），极少数切分歧义场景可能与 jieba/fugashi 略有出入。论文实验请使用 exe 版或源码版。

**Q7：如何更换或扩充词典？**
编辑 trilingual_sentiment/data/ 下的 CSV/TXT 文件即可（格式见文件头注释）；或在代码中调用 analyzer.add_word() / analyzer.load_lexicon()。便携版需重跑 python tools/build_portable.py 同步。

**Q8：可以在 macOS / Linux 使用吗？**
可以：便携版直接可用；源码版执行 ./start.sh；Windows 版 exe 仅限 Windows。

**Q9：如何修改端口？**
源码版：PORT=9000 python webapp/app.py。exe 版会自动在 8765～8784 中寻找空闲端口。

## 第8章 二次开发与 API

### 8.1 REST API

POST /api/analyze，请求体 {"text": "文本"}，返回字段：

| 字段 | 含义 |
|---|---|
| language | 整体语言识别结果（code / name / confidence / counts） |
| index | 整体倾向分（-100～100，无命中为 null） |
| label | 极性标签 |
| score | 原始加权总分 |
| matched_count / sentence_count | 命中词数 / 句子数 |
| sentences[] | 逐句结果（语言、标签、index、matched、tokens、warnings） |

空文本返回 HTTP 400。

### 8.2 Python API

    from trilingual_sentiment import SentimentAnalyzer
    az = SentimentAnalyzer()
    r = az.analyze("非常不好", "zh")   # r.label / r.score / r.matched
    d = az.explain("非常好", "zh")     # 含分词标注 tokens

### 8.3 扩展点

- 词典：trilingual_sentiment/data/*.csv（word,score）；加载器支持 HowNet 目录、MPQA .lex、単語感情極性対応表 pn.csv。
- 规则：data/*_negation.txt（否定词）、data/*_degree.csv（程度词权重）；窗口大小与权重上限在 SentimentAnalyzer 构造参数中配置。
- 新语言：注册 LanguageProfile（分词器 + 词典 + 规则）即可。

### 8.4 重新构建
